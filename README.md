# 蛇梯棋 (Snakes and Ladders)

终端版蛇梯棋：10×10 棋盘、掷骰前进、梯子爬升、蛇头滑落，精确到达 100 获胜。纯 Python 标准库。

## 玩法

- 棋盘 100 格，蛇形编号（1 在左下角）。
- 每轮掷 6 面骰走对应步数；踩到 `▲` 梯底爬到梯顶，踩到 `▼` 蛇头滑到蛇尾。
- **必须精确到达 100**：掷出的步数会超出 100 时，原地不动。
- 交互模式：每位玩家轮流按回车掷骰（`q` 退出）。

## 用法

```bash
python -m snakes_ladders                 # 人机交互（需要终端）
python -m snakes_ladders --auto         # 自动掷骰演示 10 局
python -m snakes_ladders --auto --games 50 --seed 42
python -m snakes_ladders --auto --verbose   # 打印每一步
python -m snakes_ladders --players 4    # 4 名玩家
```

示例输出（真实运行）：


## 诚实局限

- **纯运气游戏**：没有任何决策点，所谓的 "AI 对局" 只是自动掷骰演示，没有策略可言。
- 超出 100 的规则采用"原地不动"（部分规则用"反弹"），本项目取简化版。
- 文本棋盘，无图形/动画/存档；Python 3.10+，纯标准库。
